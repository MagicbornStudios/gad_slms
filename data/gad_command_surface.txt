===== gad snapshot =====
Print all planning files inlined for a project (gad snapshot v1.35.0)

USAGE gad snapshot [OPTIONS] 

OPTIONS

         --projectid    Project ID (default: first root)                                                                                                                                                                                                                                       
           --project    Project ID (alias for --projectid)                                                                                                                                                                                                                                     
           --phaseid    Scope snapshot to one phase id                                                                                                                                                                                                                                         
            --taskid    Scope snapshot to one task id                                                                                                                                                                                                                                          
           --agentid    Existing agent id to reuse                                                                                                                                                                                                                                             
              --role    Logical agent role for auto-registration                                                                                                                                                                                                                               
           --runtime    Runtime identity override (claude-code, codex, cursor, human, etc.)                                                                                                                                                                                                    
    --parent-agentid    Parent/root agent id when bootstrapping a subagent lane                                                                                                                                                                                                                
     --model-profile    Model profile attached to the lane                                                                                                                                                                                                                                     
    --resolved-model    Resolved concrete model attached to the lane                                                                                                                                                                                                                           
              --full    Full dump (no sprint filtering)                                                                                                                                                                                                                                        
              --json    JSON output                                                                                                                                                                                                                                                            
        --skills="5"    Number of equipped skills to surface (44-35). 0 disables. Default: 5.                                                                                                                                                                                                  
              --mode    full (default) | active — "active" emits ONLY STATE.xml next-action + current phase + open sprint tasks (skips static catalog, references, decisions). Decision gad-195: static info loaded once at session start, active info re-pullable cheap without context waste.
           --session    Session ID. When provided, auto-downgrades to mode=active if static context was already delivered in this session. Env fallback: GAD_SESSION_ID.                                                                                                                       
         --sessionid    Session ID alias for --session (runtime command compatibility).                                                                                                                                                                                                        
  --format="compact"    compact (default) | xml — "compact" strips XML envelope tokens (prolog, outer tags, per-item tag pairs) while preserving content. "xml" dumps raw file content (legacy). Decision gad-241.                                                                             
             --terse    Terse snapshot: sprint scope + active phase + open task count + last 3 state-log entries. Target <500 tokens.                                                                                                                                                          
   --no-side-effects    Read-only snapshot: suppress session/lane/log/graph writes.                                                                                                                                                                                                            
           --handoff    Handoff ID. Emits a unified pipe-able prompt: orientation + matched skill bodies + handoff body. Used by team workers as gad snapshot --handoff <id> | runtime (task 107-10).

===== gad handoffs =====
Work-stealing handoff queue — list, show, claim, claim-next, unclaim, complete, create, create-closeout, lint, new (gad handoffs v1.35.0)

USAGE gad handoffs list|show|claim|claim-next|unclaim|complete|create|create-closeout|lint|new

COMMANDS

             list    List handoffs (default: open bucket)                                                                                                                                   
             show    Print full content of a handoff file                                                                                                                                   
            claim    Claim an open handoff (moves open→claimed)                                                                                                                             
       claim-next    Claim the best-matching open handoff for the current runtime. Respects runtime_preference + priority, then FIFO. Prints the handoff body so the caller can dispatch it.
          unclaim    Return a claimed handoff to open (moves claimed→open)                                                                                                                  
         complete    Mark a claimed handoff complete (moves claimed→closed)                                                                                                                 
           create    Create a new handoff in open/                                                                                                                                          
  create-closeout    Create a closeout handoff: evidence that a task in another lane was completed by you. Receiving lane sweeps + marks the task done in TASK-REGISTRY.                    
             lint    Retroactively grade all handoffs in open/ + claimed/ against the quality contract                                                                                      
              new    Create a prefilled handoff from the handoff-template.md template                                                                                                       

Use gad handoffs <command> --help for more information about a command.


===== gad evolution =====
Manage GAD evolution proto-skills (validate/promote/discard/status/similarity/images) and project level (level-up) (gad evolution v1.35.0)

USAGE gad evolution scan|install|validate|promote|discard|status|report|similarity|shed|skill-usage|images|level-up

COMMANDS

         scan    Run the lightweight evolution scan and write .planning/.evolution-scan.json                                              
      install    Install a staged proto-skill into one or more coding-agent runtimes without promoting it                                 
     validate    Run advisory validator on a proto-skill (writes VALIDATION.md)                                                           
      promote    Promote a proto-skill into skills/ + workflows/ (joins species DNA)                                                      
      discard    Discard a proto-skill (deletes the directory)                                                                            
       status    Show evolution state - pending proto-skills + candidates                                                                 
       report    Write a game-screen evolution summary to .planning/.evolutions/<ts>-evolution-NN.md                                      
   similarity    Compute semantic similarity matrix across candidates + proto-skills (offline, no API)                                    
         shed    Dry-run or confirm shedding of unused skills; legacy candidate shedding remains available behind --all/--obsolete/<slug>.
  skill-usage    Report per-slug per-runtime skill invocation counts from .gad-log/skill-loads.                                           
       images    Skill image inventory + optional OpenAI generation (opt-in)                                                              
     level-up    Advance project evolution level if XP threshold is met. Forces session reset.                                            

Use gad evolution <command> --help for more information about a command.
