### Memory Fix Required For All Training Scripts

The training loop in all 3 scripts needs this pattern:
```python
import gc

# In the training loop, after optimizer.step():
loss_val = loss.item()  # capture scalar BEFORE deleting
optimizer.zero_grad(set_to_none=True)
loss.backward()
torch.nn.utils.clip_grad_norm_(model.parameters(), 1.0)
optimizer.step()
del loss  # FREE the computation graph
gc.collect()  # Force garbage collection on CPU
```

Also add bfloat16 autocast for CPU training:
```python
with torch.autocast(device_type="cpu", dtype=torch.bfloat16):
    _, loss, _ = model(x, y)
```
